# OnChain Research Papers

This directory contains research papers related to CheckOnChain metrics analysis.

## Directory Structure

- `papers/sopr_analysis/` - Papers analyzing SOPR (Spent Output Profit Ratio)
- `papers/nupl_analysis/` - Papers analyzing NUPL (Net Unrealized Profit/Loss)
- `papers/mvrv_analysis/` - Papers analyzing MVRV (Market Value to Realized Value)
- `papers/mining_economics/` - Papers analyzing Bitcoin mining economics
